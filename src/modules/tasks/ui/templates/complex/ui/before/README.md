# `complex.before`

Одно поле `MathInput`, подпись слева. Собрана потоком CX волны 1 (26.11.2026) из фабрики семейства — та же
вёрстка, что у соседних раскладок 4 класса.

## Когда выбирать

`answerInput` одно поле, непустой `before`, пустой `after`.

## Контракт данных

См. [data/task.json](data/task.json) (`Elixir.Task_1_6_11`). Примеры — из выгрузки
генераторов 02.08 (`variants.json`), классы: 0, 1, 2, 3, 5, 6, 7, 10, 11. Строки длиннее
200 символов выгрузка урезает: урезанный рисунок заменён помеченной заглушкой
(`truncated: true` в [data/all-tasks.json](data/all-tasks.json)). Боевые данные приходят целиком.
