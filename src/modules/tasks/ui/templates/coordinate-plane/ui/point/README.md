# coordinatePlane.point — отметить точку на плоскости

Ребёнок нажимает на плоскость; нажатие привязывается к ближайшему узлу сетки,
там появляется брендовая точка с подписью координат. Повторное нажатие на
точку её снимает. Если точек нужно несколько (`figure.drawingFigure` 15),
каждое нажатие добавляет или снимает свою.

Ответ — строка `(x;y)`, несколько точек через разделитель мультиответа, по
возрастанию. Эту форму бэк принимал для точек боевыми сабмитами (qalan-assets,
`trainer/src/lib/checkAnswer.ts`, `Task_5_3_4_8`).

Плоскость — объявленное поле целиком, без подгонки под рисунок: ответ может
лежать там, где ничего не нарисовано (`Task_2_18_6_7`). Уже нарисованное
(точки, отрезки, многоугольники, окружности) — общие `PlaneAxes` и
`PlaneFigure` из составной задачи.

Не входит: графики функций по формуле (фигура 120, 10 класс) и координатный
луч (`Task_5_3_4_7/8` — эталон с `y = 0.5`, в узел сетки не попадает).
